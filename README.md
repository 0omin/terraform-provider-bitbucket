# Terraform Provider for Bitbucket Cloud

A Terraform provider for managing Bitbucket Cloud resources through the Bitbucket Cloud REST API 2.0.

## Status

This provider is under development. No version has been released yet, and it has no resources or data sources yet.

## Development

Requires Go 1.26 or later.

```sh
make build   # build the provider binary
make test    # run the tests
make vet     # run go vet
```
